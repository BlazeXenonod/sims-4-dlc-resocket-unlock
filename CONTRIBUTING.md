When you first open the application, it will automatically scan your Sims 4 mod folder (usually located in Documents > Electronic Arts > The Sims 4 > Mods). The tool will display all your mods in an organized list.

### Mods Not Appearing
If your mods aren't showing up, make sure:
- Your Mods folder is in the correct location
- The mods have the correct file extensions (.package or .ts4script)
- You've enabled mods in your Sims 4 game settings

### Application Won't Start
Try these solutions:
- Run the application as administrator (right-click > Run as administrator)
- Check if your antivirus is blocking the application
- Reinstall the application if the problem persists

- Use the "Safe Mode" feature to quickly disable all mods
- Re-enable mods one by one to find the problematic one
- Check the conflict detection results for warnings
